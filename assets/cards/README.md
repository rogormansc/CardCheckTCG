These are artwork reference sources, not product affiliations or live-price data sources. The initial interpretation of “(2025)” is card number 205, with 204 offered as an alternate printing. Confirm the number on the physical card.

Pokémon card artwork is owned by its respective rights holders. Do not infer that the app source-code license applies to reference artwork. You can substitute your own clear reference photographs of the exact physical cards. Training and scans run on the device; this project does not require sending user photos to the artwork source.

Run `npm run setup` from the project root to download the original PNGs. The creator's execution environment blocked direct external image downloads, so no card artwork bytes are included until setup succeeds on your own network. The app can also load the remote source with CORS where supported and reports which references are actually indexed.
