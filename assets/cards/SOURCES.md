# Card reference sources

The card-reference PNGs can be downloaded with `npm run setup` using the dependency-free script `tools/download-references.mjs`. The script verifies that each response is a card-sized PNG before saving it. It does not generate or modify the card artwork.

| Filename to save in this folder | Verified source URL |
| --- | --- |
| `umbreon-v-189.png` | https://images.pokemontcg.io/swsh7/189_hires.png |
| `gardevoir-sylveon-gx-205.png` | https://images.pokemontcg.io/sm10/205_hires.png |
| `gardevoir-sylveon-gx-204.png` | https://images.pokemontcg.io/sm10/204_hires.png |

Source images and exact identifiers were checked on 15 November 2026. Card identities are supported by the [official Evolving Skies checklist](https://assets.pokemon.com/assets/cms2/pdf/trading-card-game/checklist/swsh7_web_cardlist_en.pdf) and [official Unbroken Bonds checklist](https://assets.pokemon.com/assets/cms2/pdf/trading-card-game/checklist/sm10_web_cardlist_en.pdf). The artwork source is Pokémon TCG API's image host, not an official product endorsement.

All Pokémon artwork and trademarks belong to their respective rights holders. The original app code's MIT license does not license third-party card artwork. Reference matching is a classroom demonstration and is separate from card authentication or automated condition grading.

Direct downloads were blocked by the creator's execution environment. If automated setup fails on your own network, save each linked PNG manually with the filename above, or use your own clear photo of the exact printing through the app's Catalog controls. Until an image is loaded and indexed, that card is not ready for recognition.
